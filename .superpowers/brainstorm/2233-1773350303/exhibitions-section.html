Database Design

-- New tables

exhibition_years {
  id, year (int, unique), is_active (bool)
}

exhibition_items {
  id, year_id (FK), type (exhibition | moment | news),
  title, description, image_url,
  -- news-specific fields:
  source_name, article_url,
  display_order, is_active
}

Admin Panel

  • Year Management — add/remove years, toggle active status
  • Items per Year — select year → add items with type selector (Exhibition / Moment / News)
  • News fields — source name + article URL (only shown when type = news)
  • Drag to reorder items within each year/type
  • Bulk upload — upload multiple photos at once for a year's exhibitions/moments
