Key Differences from Sarom

  • Brand colors — purple (#2F2582) headers instead of Sarom's grey/olive
  • Rounded corners — 12px radius cards matching our design system
  • Modern filter modal — clean modal with Apply/Clear buttons instead of plain dropdown
  • Responsive — 4 cols → 2 cols on tablet → 1 col on mobile
  • Map below — interactive markers instead of generic iframe
  • Same admin — existing /admin/stores manages all data, no changes needed
