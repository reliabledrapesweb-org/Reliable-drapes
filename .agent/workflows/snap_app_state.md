---
description: Take screenshots of all app pages (desktop & mobile) and generate a social media post.
---

1. **Identify Pages**: The application has the following main routes:
   - Home: `/`
   - About: `/about`
   - E-Catalogue: `/e-catalogue`

2. **Take Screenshots**:
   - For each route (`/`, `/about`, `/e-catalogue`):
     - Open the page in a browser using `http://localhost:3000`.
     - Take a screenshot in **Desktop Mode** (viewport size: 1920x1080). Save as `[page_name]_desktop.png`.
     - Take a screenshot in **Mobile Mode** (viewport size: 375x812). Save as `[page_name]_mobile.png`.
   - Ensure all screenshots are saved to the artifacts directory.

3. **Generate Social Media Post**:
   - Review the captured screenshots to understand the current state and visual appeal of the application.
   - Draft a catchy and engaging post for X (formerly Twitter) that highlights the progress/features shown in the screenshots.
   - Include relevant hashtags (e.g., #buildinpublic, #webdev, #nextjs).
   - Present the draft to the user.
