---
description: Git add, commit, and push changes
---

1. Add all changes

   ```bash
   git add .
   ```

2. Commit changes

   ```bash
   git commit -m "Update codebase"
   ```

   > Note: You should probably ask the user for a specific commit message or infer it from the changes.

3. Push to remote
   ```bash
   git push
   ```
